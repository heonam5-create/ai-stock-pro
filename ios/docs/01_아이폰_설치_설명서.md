# AI 주식 분석센터 PRO — 아이폰(iOS) 설치 설명서

> 아이폰은 Apple 정책상 **서명되지 않은 앱 파일(IPA)을 링크 한 번으로 설치할 수 없습니다.**
> 정상적인 설치 경로는 **TestFlight**(베타 배포) 또는 **App Store**뿐이며, 둘 다 **Apple Developer Program 가입(유료)** 이 필요합니다.
> 이 저장소에는 가입 후 시크릿만 등록하면 **자동으로 빌드·서명·TestFlight 업로드**까지 되는 설정이 들어 있습니다.

## 0. 현재 상태 (자동화된 부분)
| 단계 | 상태 |
|---|---|
| iOS 소스코드 (Swift / SwiftUI) | ✅ `ios/` 폴더 |
| Xcode 프로젝트 | ✅ `ios/project.yml` → CI 에서 `AIStockPro.xcodeproj` 자동 생성 (Actions 산출물 `AIStockPro-Xcode-Project` 로 다운로드 가능) |
| 컴파일·단위 테스트·실시세 검증 | ✅ GitHub Actions `iOS 빌드·테스트` (macOS 러너) |
| 시뮬레이터 실행 스크린샷 | ✅ `ios/docs/screenshots/` |
| 서명 + TestFlight 업로드 | ⏸ Apple 시크릿 등록 시 자동 실행 (아래 3~5단계) |
| TestFlight 설치 링크 | ⏸ App Store Connect 에서 생성 (아래 6단계) |

## 1. Apple Developer Program 가입 (사용자 직접)
- 주소: https://developer.apple.com/programs/enroll/
- 비용: **연 99달러** (한국 결제 시 연 ₩129,000 내외, 환율에 따라 변동)
- 준비물: 이중 인증이 켜진 Apple ID, 본인 명의 결제 수단
- 개인(Individual)으로 가입하면 됩니다. 승인까지 보통 수 시간~2일.
- 가입 후 **Membership details** 화면의 **Team ID**(영문·숫자 10자리)를 메모하세요.

## 2. 앱 ID 등록 + App Store Connect 앱 만들기 (사용자 직접, 1회)
1. https://developer.apple.com/account/resources/identifiers → `+` → App IDs → App
   - Bundle ID(Explicit): `com.heonam5.aistockpro` (다른 값을 쓰려면 GitHub 저장소 **Settings → Secrets and variables → Actions → Variables** 에 `IOS_BUNDLE_ID` 로 등록)
   - Capabilities 는 기본값 그대로 (Push Notifications 불필요)
2. https://appstoreconnect.apple.com → 앱 → `+` 신규 앱
   - 플랫폼 iOS, 이름 `AI 주식 분석센터 PRO`, 기본 언어 한국어, 번들 ID 위에서 만든 것, SKU 아무 문자(예: aistockpro)

## 3. App Store Connect API 키 만들기 (사용자 직접, 1회)
1. App Store Connect → **사용자 및 액세스 → 통합(Integrations) → App Store Connect API → 팀 키** → `+`
2. 이름 `github-actions`, 액세스 **관리(Admin)** 선택
   - Admin 이어야 CI 가 배포 인증서·프로비저닝 프로파일을 자동으로 만들 수 있습니다.
3. 생성 후 **API 키 다운로드(.p8)** — 한 번만 받을 수 있으니 안전하게 보관하세요.
4. 화면의 **키 ID** 와 상단의 **Issuer ID** 를 메모하세요.

## 4. GitHub 시크릿 등록 (사용자 직접, 1회)
저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에 4개 등록:

| 이름 | 값 |
|---|---|
| `APPLE_TEAM_ID` | 1단계의 Team ID |
| `ASC_KEY_ID` | 3단계의 키 ID |
| `ASC_ISSUER_ID` | 3단계의 Issuer ID |
| `ASC_KEY_P8` | 다운로드한 `AuthKey_XXXX.p8` 파일을 메모장으로 열어 **전체 내용**(BEGIN~END 포함)을 붙여넣기 |

> 이 값들은 GitHub 이 암호화해 보관하며 로그에도 표시되지 않습니다. 저장소 파일·채팅에 붙여넣지 마세요.

## 5. 자동 빌드·TestFlight 업로드
- 저장소 → **Actions → iOS 빌드·테스트 → Run workflow** (또는 `ios/` 수정 후 push)
- `서명·TestFlight 업로드` 단계가 초록색이면 App Store Connect 로 업로드된 것입니다.
- App Store Connect → 앱 → **TestFlight** 에서 빌드 처리 완료까지 10~30분.
- 처음 한 번 **수출 규정 준수(암호화)** 질문이 나오면 "아니요"(표준 HTTPS 만 사용, Info.plist 에 이미 표시됨).

## 6. 아이폰에 설치 (TestFlight)
### 본인·가족 (내부 테스터, 심사 없음, 최대 100명)
1. App Store Connect → 사용자 및 액세스 에서 테스터를 사용자로 추가
2. TestFlight → 내부 테스팅 → 그룹 만들기 → 테스터 추가 → 빌드 선택
3. 아이폰에 App Store 에서 **TestFlight** 앱 설치 → 초대 메일의 **"View in TestFlight"** → **설치**
4. 홈 화면의 **AI 주식 분석센터 PRO** 아이콘을 누르면 실행됩니다.

### 지인 공유용 공개 링크 (외부 테스터, 최대 1만 명)
1. TestFlight → 외부 테스팅 → 그룹 만들기 → 빌드 추가 → **베타 앱 심사 제출** (첫 빌드 보통 1일 내외)
2. 승인 후 그룹 화면에서 **공개 링크 활성화** → `https://testflight.apple.com/join/XXXX` 링크 생성
3. 받는 사람: 링크 터치 → TestFlight 설치 → **수락 → 설치**
- TestFlight 빌드는 업로드 후 **90일**간 사용 가능합니다. 이후에는 새 빌드를 올리면 됩니다 (push 하면 자동).

## 7. App Store 정식 출시 (선택)
- App Store Connect 에서 설명·키워드·스크린샷(`ios/docs/screenshots` 참고)·**개인정보처리방침 URL**·개인정보 수집 항목(이 앱은 서버로 개인정보를 보내지 않음)·연령 등급을 입력하고 심사 제출.
- ⚠ **심사 거절 가능성**: 이 앱은 네이버 금융·Yahoo Finance 의 **비공식 공개 데이터**를 사용합니다. Apple 심사지침 5.2(제3자 콘텐츠 권한)에 따라 데이터 사용 권한 증빙을 요구받거나 거절될 수 있습니다. 정식 출시를 원하면 한국투자증권 Open API 등 **사용 계약이 있는 시세 공급원**으로 교체하는 것을 권장합니다.
- 본인·지인 사용 목적이라면 **TestFlight 배포가 현실적인 방법**입니다.

## 8. 유료 가입 없이 쓰는 방법 (Mac 필요)
- Mac + Xcode 에서 `ios/project.yml` 로 프로젝트를 만들고(`brew install xcodegen && cd ios && xcodegen generate`), 무료 Apple ID 로 본인 아이폰에 직접 설치할 수 있습니다.
- 단, 무료 서명은 **7일마다 다시 설치**해야 하며 다른 사람에게 배포할 수 없습니다.

## 9. 주가 알림의 한계 (iPhone)
- 앱을 열어 둔 동안: 시세 새로고침 때마다 즉시 확인
- 앱을 닫은 뒤: iOS **백그라운드 앱 새로고침**으로 확인 — 실행 시점은 iOS 가 결정하며(보통 15분~수 시간), 저전력 모드·앱 사용 빈도에 따라 실행되지 않을 수 있습니다.
- 24시간 확실한 감시가 필요하면 **서버(클라우드)에서 가격을 감시하고 APNs 푸시**를 보내는 구조가 필요합니다. 서버 운영비·APNs 인증서(유료 개발자 계정)가 필요하며 이 저장소에는 포함되어 있지 않습니다.
- 설정 앱 → 일반 → **백그라운드 앱 새로고침**을 켜 두세요.

## 10. 데이터 출처
- 현재가(기본): 네이버 금융 — 응답의 지연 시간(delayTime)과 체결 시각으로 '실시간' 여부를 판단하며 무조건 실시간으로 가정하지 않습니다.
- 보조·대체: Yahoo Finance (교차검증, 미국 분봉, 네이버 실패 시 "지연 가능 / 대체 데이터 사용 중" 표시)
- 종목 목록: KRX KIND 상장법인목록 + 네이버 금융 + Nasdaq Trader (매주 자동 갱신 — `종목 목록 갱신` 워크플로)
- 미국 '주간거래'(야간 대체거래소) 가격은 무료 공급원에서 제공되지 않아 표시하지 않습니다.
