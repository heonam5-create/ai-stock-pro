# AI 주식 분석센터 PRO — 아이폰 무료 웹앱(PWA) 설치 안내

**설치 주소:** https://heonam5-create.github.io/ai-stock-pro/

Apple Developer 가입·App Store·TestFlight 없이 **완전 무료**로 설치합니다.

## 1. 아이폰에 설치 (30초)
1. 아이폰 **Safari** 로 위 주소를 엽니다. (카카오톡 등 앱 내 브라우저에서 열렸다면 오른쪽 아래 메뉴 → "Safari로 열기")
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**
3. 홈 화면의 **AI주식PRO** 아이콘을 누르면 주소창 없이 전체 화면 앱으로 바로 실행됩니다.
- iOS 16.4 이상 권장 (알림 기능은 16.4 이상, 홈 화면에 추가한 앱에서만 동작)
- 업데이트는 자동입니다 (앱을 다시 열면 최신 버전 적용).

## 2. 데이터 모드 — 꼭 읽어 주세요
네이버 금융·Yahoo 는 **웹 브라우저(다른 사이트)에서 직접 데이터를 가져가는 것을 차단**합니다 (2026-11 실측: 네이버 HTTP 403, Yahoo CORS 미허용).
그래서 무료 정적 호스팅만으로는 앱판과 같은 실시간 조회가 불가능하며, 아래 두 방식을 제공합니다.

| | 스냅샷 모드 (기본, 설정 불필요) | 실시간 모드 (선택, 무료 계정 1개 필요) |
|---|---|---|
| 시세 | 서버(GitHub Actions)가 주기적으로 모은 **네이버 전 종목 시세** — **지연**(수집 시각 표시) | 네이버 실시간(공급원 표기 지연 0분), Yahoo 교차검증 |
| 갱신 주기 | 장중 약 20분 간격 (GitHub 일정 실행 지연 시 더 늦을 수 있음) | 한국 10초 · 미국 15초 자동 새로고침 |
| 차트·AI 분석 | 시가총액 상위 약 300(한국)+300(미국) 종목 일봉 | 전 종목, 분봉~월봉 |
| 뉴스 | 상위 종목 + 경제 뉴스 | 전 종목 |
| 종목 검색 | 한국 전체 · 미국 전체 (오프라인 동작) | 동일 + 네이버 자동완성 |
| BEST 5 | 일봉 보유 종목 중 분석 | 시가총액 상위 300·400 후보 분석 |

- 스냅샷 시세는 화면에 **"지연 (스냅샷 N분 전 수집)"** 으로 표시되며, 장중 45분 넘게 지난 스냅샷은 **⚠ 시세 지연** 으로 표시하고 매수·매도가를 숨깁니다.
- 스냅샷 자동 갱신(일정 실행)은 저장소의 **기본 브랜치(main)에 반영된 뒤**부터 동작합니다.

## 3. (선택) 실시간 모드 켜기 — Cloudflare Workers 무료
Cloudflare Workers 무료 플랜(하루 10만 요청)에 시세 중계 서버를 올립니다. 비용 없음, 신용카드 불필요.
1. https://dash.cloudflare.com/sign-up 에서 무료 가입 (이메일 인증)
2. **API 토큰 만들기**: 내 프로필 → API 토큰 → 토큰 생성 → 템플릿 **"Cloudflare Workers 편집(Edit Cloudflare Workers)"** → 계정 리소스: 내 계정 → 생성 → 토큰 복사
3. **계정 ID**: 대시보드 → Workers 및 Pages → 오른쪽의 **계정 ID** 복사
4. GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
   - `CLOUDFLARE_API_TOKEN` = 2의 토큰
   - `CLOUDFLARE_ACCOUNT_ID` = 3의 계정 ID
5. 저장소 → Actions → **PWA 웹앱 배포 → Run workflow** — 중계 서버가 배포되고 웹앱에 주소가 자동 설정됩니다.
- 중계 서버(`pwa-proxy/worker.js`)는 **API 키를 저장하지 않으며**, 네이버·Yahoo·Google 뉴스 주소만 중계하고 이 웹앱 주소에서 온 요청만 허용합니다.
- 직접 만든 Worker 주소가 있다면 웹앱 **설정 › 실시간 프록시 주소** 에 입력해도 됩니다.

## 4. 외부 AI (선택, 유료)
- 기본 AI 분석은 **앱에 내장된 무료 분석 엔진**입니다 (안드로이드·iOS판과 동일 규칙).
- OpenAI 등 외부 AI 는 **본인 API 키로 사용량만큼 요금이 부과되는 유료 서비스**입니다. 설정에서 주소·모델·키를 입력하면 사용할 수 있습니다.
- 키는 **이 아이폰의 브라우저 저장소에만** 보관되고 API 제공사로 직접 전송됩니다. 저장소·웹앱 소스·중계 서버에는 어떤 키도 없습니다.

## 5. 알림의 한계
- 앱을 **열어 둔 동안** 시세가 갱신될 때마다 조건을 확인해 알림을 띄웁니다.
- 앱을 닫은 뒤에도 감시하려면 웹 푸시 서버(유료 또는 별도 서버 운영)가 필요해 이 무료 웹앱에는 포함되지 않습니다.

## 6. 데이터 이용 조건
- 네이버 금융·Yahoo Finance·Google 뉴스의 공개 데이터는 비공식 경로이며 **개인·비상업 열람 용도**로만 사용하세요.
- 공급원 정책 변경 시 조회가 실패할 수 있으며, 앱은 오류로 표시하고 임의 가격을 만들지 않습니다.
- 미국 '주간거래'(야간 대체거래소) 가격은 무료 공급원이 제공하지 않습니다.
