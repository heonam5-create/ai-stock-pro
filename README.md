# AI 주식 분석센터 PRO (안드로이드)

한국·미국 주식을 한글로 검색하고, 실제 무료 시세로 차트·AI 종합 분석·매수/매도가·추천 BEST 5·뉴스·관심종목·알림을 제공하는 **안드로이드 세로모드 전용 앱**입니다.

| 항목 | 내용 |
|---|---|
| 개발 방식 | Kotlin + Jetpack Compose (네이티브 안드로이드) |
| 지원 기기 | Android 8.0 이상 (삼성 갤럭시, 갤럭시 폴드 접힌 화면 포함) |
| 설치 | APK 파일 1개 → 터치 설치 → 홈 화면 아이콘 |
| 비용 | 기본 기능 전부 무료 (API 키 불필요). 선택 키도 무료 |

## 가장 빠른 시작 (PC 프로그램 설치 불필요)
1. 이 폴더 전체를 GitHub 저장소에 올립니다 → **자동으로 APK가 만들어집니다.**
2. 휴대폰으로 저장소의 **Releases** 페이지에서 APK를 받아 설치합니다.

자세한 순서: [`docs/01_설치_설명서.md`](docs/01_설치_설명서.md)

## 폴더 구조
```
app/src/main/java/com/aistock/pro/
 ├─ MainActivity.kt / StockApp.kt     앱 시작점
 ├─ data/        시세(Yahoo)·뉴스(Google RSS)·공공데이터·Finnhub·저장소·캐시
 ├─ analysis/    기술지표·AI 분석 엔진·매매가 계산·BEST5 점수·뉴스 분류
 ├─ ui/          화면 5개(홈·종목 분석·BEST5·관심 종목·설정), 터치 차트
 └─ worker/      백그라운드 주가 알림
app/src/test/    분석 엔진 자동 테스트 (16개)
.github/workflows/build-apk.yml   APK 자동 빌드
```

※ 투자 권유가 아닌 참고용 분석 도구입니다. 무료 시세는 지연될 수 있습니다.
