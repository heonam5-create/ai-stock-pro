# 05. 오류 수정 및 유지보수 방법

## 빌드 실패 시 (GitHub Actions 빨간 X)
1. Actions → 실패한 작업 → 빨간 단계 클릭 → 로그에서 `e: ` 로 시작하는 줄(Kotlin 오류)이나 `FAILURE:` 아래 내용을 복사
2. 새 대화에서 Claude 에게 **"AI 주식 분석센터 PRO 빌드 오류"** 라고 하고 그 로그와 `PROJECT_STATUS.md` 를 붙여넣으면 수정본을 받을 수 있습니다.
3. 수정된 파일만 GitHub 에서 해당 파일 열기 → 연필(✏️) 아이콘 → 내용 교체 → Commit → 자동 재빌드

## 앱 사용 중 자주 생길 수 있는 문제
| 증상 | 원인 | 해결 |
|---|---|---|
| "호출 한도에 잠시 걸렸습니다" | Yahoo 429 (짧은 시간 과다 호출) | 1~2분 후 다시 시도. BEST5 를 연속 실행하지 않기 |
| 검색은 되는데 시세가 안 나옴 | 상장폐지·거래정지·시장 이전 | 앱이 코스피↔코스닥 자동 재시도. 그래도 안 되면 6자리 코드로 검색 |
| 한글 종목이 검색 안 됨 | 내장 사전(한국 119·미국 71종목)에 없음 | 6자리 코드로 검색하거나 설정에 공공데이터 키 등록 |
| 분봉 버튼이 회색 | 해당 종목 분봉 데이터 미제공 | 정상 동작(이유 표시). 일봉 이상 사용 |
| 알림이 늦게 옴 | 안드로이드 15분 최소 주기·절전 | 설정 > 배터리 최적화 제외, 알림 주기 15분 |
| 앱 전체가 데이터 없음 | Yahoo 주소 정책 변경 | `data/YahooSource.kt` 수정 필요 → Claude 에게 요청 |

## 수정 후 확인
- GitHub 에 올리면 Actions 가 **분석 엔진 자동 테스트(16개)** 를 먼저 실행하고, 통과해야 APK를 만듭니다.
- 새 APK를 기존 앱 위에 설치하면 데이터가 유지됩니다 (GitHub Secrets 에 등록한 서명키 절대 변경 금지).

## 앱이 갑자기 종료되지 않도록 한 장치
- 모든 네트워크 작업은 오류를 잡아 화면에 한국어 안내 + "다시 시도" 버튼으로 표시
- ViewModel 전역 예외 처리기(CoroutineExceptionHandler) → 예상 못한 오류도 하단 알림 메시지로 표시
- 저장 데이터 읽기 실패 시 빈 목록으로 복구, 알림 작업 실패 시 다음 주기 재시도
