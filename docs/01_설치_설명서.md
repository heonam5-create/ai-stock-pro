# 01. 설치 설명서 (개발 지식 없이 따라하기)

APK는 "안드로이드 설치 파일"입니다. 이 프로젝트는 **GitHub(무료 코드 저장 사이트)가 APK를 대신 만들어 주도록** 설정되어 있어, PC에 Android Studio·Java 등을 설치할 필요가 없습니다.

---

## 1단계. GitHub 가입 (최초 1회, 5분)
1. PC 또는 휴대폰 브라우저에서 https://github.com 접속 → **Sign up**(가입)
2. 이메일·비밀번호·아이디 입력 후 이메일 인증

## 2단계. 저장소(폴더) 만들기
1. 로그인 후 오른쪽 위 **＋** → **New repository**
2. Repository name: `AIStockPro`
3. **Private(비공개)** 선택을 권장합니다 (이유: 프로젝트에 앱 서명키가 포함되어 있음)
4. **Create repository** 클릭

## 3단계. 소스 올리기 (PC 권장)
1. 받은 `AIStockPro.zip` 압축을 풉니다.
2. 방금 만든 저장소 화면에서 **uploading an existing file** 링크를 클릭
3. 압축을 푼 `AIStockPro` 폴더 **안의 내용 전체**(app, docs, gradle, .github 폴더와 파일들)를 선택해 브라우저 창에 끌어다 놓습니다.
   - `.github` 폴더가 꼭 포함되어야 자동 빌드가 됩니다.
4. 아래 **Commit changes** 클릭

> `.github` 폴더가 올라가지 않았다면: 저장소 상단 **Actions** 탭 → **set up a workflow yourself** → 파일 이름을 `build-apk.yml` 로 하고, 프로젝트의 `.github/workflows/build-apk.yml` 내용을 그대로 붙여넣고 **Commit** 하세요.

## 4단계. 자동 빌드 확인 (약 5~10분)
1. 저장소 상단 **Actions** 탭 클릭
2. "APK 자동 빌드" 작업이 노란색(진행 중) → **초록색 체크(성공)** 가 되면 완료
3. 빨간 X(실패)가 나오면 → [05_오류수정_유지보수.md](05_오류수정_유지보수.md)의 "빌드 실패 시" 참고
4. 수동으로 다시 빌드하려면: Actions → APK 자동 빌드 → **Run workflow**

## 5단계. 휴대폰에 APK 내려받기
**방법 A (휴대폰에서 바로, 권장)**
1. 휴대폰 브라우저로 GitHub 로그인 → 저장소 → 오른쪽(또는 아래)의 **Releases** → 최신 버전
2. `AI주식분석센터PRO-v1.0.N.apk` 를 눌러 다운로드

**방법 B (PC에서 받아 옮기기)**
1. Actions → 성공한 작업 클릭 → 아래 **Artifacts** 의 `AI-Stock-PRO-APK` 다운로드 (zip 안에 apk)
2. USB·카카오톡 나에게 보내기·구글드라이브 등으로 휴대폰에 옮김

## 6단계. 설치 ("출처를 알 수 없는 앱" 허용)
1. 휴대폰 **내 파일 → 다운로드** 에서 APK 파일 터치
2. "보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다" 가 나오면 → **설정** → "이 출처 허용" 켜기 → 뒤로 가기
   - 삼성 갤럭시 경로: 설정 > 애플리케이션 > (사용한 앱: 내 파일 또는 Chrome) > 출처를 알 수 없는 앱 설치 > 허용
3. **설치** → 완료 후 **열기**
4. Google Play 프로텍트가 "알 수 없는 앱" 경고를 보이면 **무시하고 설치**(또는 세부정보 > 그래도 설치)를 누릅니다. 개인이 만든 앱이라 Play 스토어 서명이 없어서 나오는 정상 경고입니다.
5. 처음 실행 시 **알림 허용** 을 누르면 주가 알림을 받을 수 있습니다.

## 업데이트 방법 (관심 종목·설정 유지)
- 수정된 파일을 GitHub에 다시 올리면 새 APK(버전 번호 증가)가 자동 생성됩니다.
- 새 APK를 그대로 설치하면 **기존 앱 위에 업데이트**되어 관심 종목·보유 정보·알림·설정이 유지됩니다.
- GitHub Secrets 에 등록한 같은 서명키로 항상 서명되므로 "앱이 설치되지 않았습니다(서명 충돌)"가 나지 않습니다. **등록한 서명키를 바꾸지 마세요.** (서명키 파일은 저장소에 올리지 않습니다)

## 서명키 등록 (업데이트 설치에 필요)
서명키는 보안상 저장소에 포함하지 않고 **GitHub Secrets** 로만 전달합니다.
1. PC에서 키 생성: `keytool -genkeypair -v -keystore release.jks -alias aistock -keyalg RSA -keysize 2048 -validity 10000`
2. Base64 변환: `base64 -w0 release.jks > release.b64` (Windows: `certutil -encode release.jks release.b64` 후 첫/끝 줄 삭제)
3. 저장소 **Settings > Secrets and variables > Actions > New repository secret** 에 4개 등록:
   `KEYSTORE_BASE64`(release.b64 내용), `KEYSTORE_PASSWORD`, `KEY_ALIAS`(aistock), `KEY_PASSWORD`
4. release.jks 는 PC에 안전하게 백업하세요. 잃어버리면 업데이트 설치가 불가능합니다.

시크릿이 없으면 임시 디버그 키로 서명된 APK가 만들어지며, 이 경우 새 버전 설치 전에 기존 앱을 삭제해야 할 수 있습니다.

## PC에서 직접 빌드하고 싶다면 (선택)
Android Studio 설치 → File > Open > `AIStockPro` 폴더 → 상단 Build > Build APK(s).
또는 명령창에서 `gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
