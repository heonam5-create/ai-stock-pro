## 개발 환경의 한계
이번 개발 환경에는 Android SDK가 없고 외부 패키지 다운로드가 차단되어 있어, **APK 빌드와 실제 휴대폰 실행은 여기서 하지 못했습니다.** 그래서 APK 빌드는 GitHub Actions 자동 빌드로 구성했고, 여기서는 가능한 범위의 실제 검증을 수행했습니다.

## C. 설치 후 직접 확인할 체크리스트 (10분)
- [ ] 앱 아이콘이 홈 화면에 생기고 바로 실행된다
- [ ] 홈에 코스피·나스닥 지수가 나온다
- [ ] `삼성전자` 검색 → 현재가·기준 시각·"지연 시세" 표시
- [ ] `NVDA` 검색 → 달러 가격 표시
- [ ] 차트: 일봉 → 5분 → 주봉 전환, 두 손가락 확대, 좌우 이동, 탭 정보
- [ ] AI 종합 분석 → 판단·10개 항목·매수/매도가·뉴스 표시
- [ ] 추천 BEST 5 → 한국/미국 각각 결과 표시 (1분 이내)
- [ ] 관심 종목 추가 → 보유 수량·평단 입력 → 손익 표시 → 앱 종료 후 재실행해도 유지
- [ ] 알림: 현재가보다 높은 '목표 매수가' 알림 추가 → '지금 확인' → 알림창 표시
- [ ] 와이파이 끄고 새로고침 → 오류 안내 + 다시 시도 버튼 (앱 종료되지 않음)
