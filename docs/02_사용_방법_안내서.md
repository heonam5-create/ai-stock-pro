## 홈
- **검색창**: `삼성전자`, `하이닉스`, `엔비디아`, `샌디스크`, `NVDA`, `MU`, `005930` 처럼 한글명·영문명·티커·6자리 코드 모두 입력 가능. 결과를 누르면 종목 분석으로 이동.
- **빠른 검색** 버튼, **시장 지수**(코스피·코스닥·S&P500·나스닥·원/달러), **최근 본 종목**, **FOMC 일정**, **경제·금리·반도체 뉴스**.

## 종목 분석 (핵심 화면)
1. **현재가**: 가격·등락률·거래량·시가총액·52주 최고/최저·**데이터 기준 시각**·장 상태(장중 지연 / 장 마감 / ⚠ 갱신 지연).
2. **차트**
   - 기간: 1분·5분·15분·30분·1시간·일봉·주봉·월봉. 데이터가 없는 단위는 자동으로 회색(비활성) 처리되고 이유가 표시됩니다.
   - 지표: MA5/10/20/60/120/200, 볼린저밴드, VWAP, 추세선, 지지/저항, 매매구간
   - 하단 보조지표: 거래량(+20일 평균), RSI, MACD, 스토캐스틱, ATR
   - 조작: **두 손가락 벌리기/오므리기 = 확대/축소**, **한 손가락 좌우 = 이동**, **탭 = 그 날의 시가·고가·저가·종가**, 위아래로 밀면 화면 스크롤
3. **AI 종합 분석** 버튼 → 5~15초 후 결과
   - **AI 종합 판단**: 적극 매수 / 분할매수 / 관망 / 분할매도 / 매수 금지·위험 / 분석 불가 + 점수(0~100) + 판단 근거 + 위험 요인
   - **10개 항목**: 현재 추세, 모멘텀, 단기 매수 적합성, 중기 보유 적합성, 거래량 변화, 매물대·지지·저항, 과매수·과매도, 변동성·갭 위험, 최신 뉴스 영향, 실적 등 주요 일정 — 각각 숫자 근거 표시
   - **매수 전략**: 1·2·3차 매수가, 매수 금지 가격대 / **매도 전략**: 1·2·3차 목표가, 손절 기준가, 추세 붕괴 기준가
     - 각 가격마다 현재가 대비 %, 기술적 근거(예: "60일 이동평균선 + 매물대"), 도달 시 대응 방법, "최근 20거래일 중 N일 장중 도달"(현실성 참고치)
     - 1차 매수가는 현재가에서 평균 하루 변동폭(ATR)의 1.2배 이내로 잡아 너무 낮은 가격만 제시되는 문제를 줄였습니다.
   - **지지선·저항선 목록**, 분석 후 차트에 선과 매수구간(붉은 띠)·매도구간(푸른 띠) 표시
   - **이 가격으로 알림 설정** 버튼(1차 매수가·1차 목표가·손절가·지지선 이탈·저항선 돌파)
4. **호재·악재 뉴스**: 최근 7일 기사만, 호재/악재/중립 필터, 제목·출처·게시 시각·관련 종목, 누르면 원문 열기
5. ♡ 버튼 = 관심 종목 등록, ↻ = 새로고침

> 분석은 항상 **일봉 2년 데이터** 기준입니다. 데이터가 120거래일 미만(신규 상장 등)이면 "분석 불가"로 표시하고 결론을 만들지 않습니다.

## 추천 BEST 5
- 🇰🇷 한국 / 🇺🇸 미국 선택 → **BEST 5 분석 시작** (20~60초)
- 각 시장 후보 36종목(+관심 종목)을 실제 데이터로 모두 분석 → 9개 평가항목(상승 추세, 거래량 증가, 기술적 지표, 성장성, 호재·악재, 변동성, 지지선과의 거리, 손익비, 단기 적합성) 점수로 순위
- 매수 금지·분할매도·분석 불가 종목과 데이터 수집 실패 종목은 제외되고, 제외/실패 수가 표시됩니다. 조건을 충족한 종목이 5개 미만이면 그만큼만 보여줍니다.
- 카드를 누르면 상세 분석 화면으로 이동

## 관심 종목
- **관심·보유 종목**: 검색해서 추가 → **보유 입력**(수량·평균 매수가·목표 매도가·손절가) → 평가금액·평가손익·수익률 자동 계산. 미국 주식은 달러 + **원화 환산 손익**(현재 환율) 표시. 맨 위에 전체 합계(원화).
- **계산기**: 추가 매수 시 새 평균단가 / 분할 매도 시 실현손익·수익률·잔여 수량
- **주가 알림** 탭: 알림 추가(목표 매수가·목표 매도가·지지선 이탈·저항선 돌파·손절가·급등·급락·거래량 급증), 켜기/끄기, 삭제, **지금 확인**
- 모든 정보는 휴대폰에 저장되어 앱을 껐다 켜도, 업데이트해도 유지됩니다.
