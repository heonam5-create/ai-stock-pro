## 중요한 사실 (정직하게 안내)
1. **Yahoo Finance는 공식 API가 아닙니다.** Yahoo가 자사 웹사이트용으로 쓰는 공개 차트 주소를 사용합니다. 2026년 1월에 다른 시세 주소(v7/quote)는 막혔고, 이 앱이 쓰는 차트 주소(v8)는 2026년 현재 작동합니다. 언제든 바뀔 수 있으며, Yahoo 약관상 **개인적·비상업적 용도로만** 사용해야 합니다. 이 앱을 판매하거나 다수에게 배포하려면 유료 라이선스 데이터(한국투자증권 Open API 등)로 교체해야 합니다.
2. **무료 실시간 시세는 없습니다.** 한국 주식은 약 20분 지연이며 앱은 "지연 시세"로 표시합니다. 장중인데 마지막 체결이 40분 이상 오래되면 "⚠ 시세 갱신 지연"을 표시합니다. 가격을 임의로 만들지 않습니다.
3. **차트 가격은 주식분할이 반영(수정)된 값**입니다. 하루 ±50% 이상 급변(분할 미반영 의심)이 감지되면 분석 화면에 경고를 표시합니다.
4. **시가총액**: Yahoo 차트에는 없어서, 키가 없으면 "미제공"으로 표시합니다 (가짜 값 표시 안 함).
5. **실적 발표일**: 미국은 Finnhub 키 등록 시 표시. 한국 기업 실적일은 무료 API가 없어 DART 공시 확인을 안내합니다.
6. **CPI·고용지표 발표일**: 무료 경제캘린더 API가 없어 뉴스로 확인하도록 안내합니다 (Finnhub 경제캘린더는 유료).
7. **BEST 5 전 종목 스캔 불가**: 무료 호출 한도 때문에 시장별 대표 36종목 + 관심 종목을 후보로 사용합니다. 후보 목록은 `StockDirectory.kt`에서 수정할 수 있습니다.
8. **제한 우회 금지 준수**: 캐시(분봉 60초·일봉 2분·BEST5 10분), 동시 요청 3~4개 제한, 429 응답 시 대기 후 재시도만 사용합니다. IP 변경·스크래핑·크롤링 우회는 사용하지 않습니다.

## API 키 보안
- 앱 코드에 비밀 키는 **하나도 포함되어 있지 않습니다.**
- 사용자가 입력한 키는 휴대폰 보안칩(Android Keystore) AES-GCM 암호화로 저장되고, 백업 대상에서 제외됩니다.

## 키 발급 방법
- **Finnhub**: https://finnhub.io → Get free API key → 가입 → Dashboard 의 API Key 복사 → 앱 설정에 붙여넣기
- **공공데이터포털**: https://www.data.go.kr → 회원가입 → "금융위원회_주식시세정보" 검색 → 활용신청(자동승인, 반영까지 최대 1~2시간) → 마이페이지 > 일반 인증키(Decoding) 복사 → 앱 설정에 붙여넣기
